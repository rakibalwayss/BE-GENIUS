# BE GENIUS — Premium Streetwear Brand Website

A minimal, high-conversion streetwear e-commerce storefront inspired by modern luxury apparel brands, tailored specifically for Bangladesh with complete Cash on Delivery (COD) flow.

## 📁 Project Location
`C:\Users\R A K I B\.gemini\antigravity\scratch\be-genius`

## 🚀 Quick Launch
1. Double-click `start_store.bat` or run:
   ```bash
   python server.py
   ```
2. Open your browser at:
   `http://localhost:5000`

---

## 💎 Features Included
- **Custom Minimalist Logo & Identity:** Geometric monogram and bold typography for "BE GENIUS - Genius, by design".
- **Dual Themes:** Instant toggle between Streetwear Dark Mode and Editorial Light Mode.
- **Top Announcement Marquee:** Continuous ticker with promotional banners and discount codes.
- **Hero Lookbook Banner:** High-resolution responsive streetwear visual with call-to-action buttons.
- **Curated Catalog:** Oversized T-Shirts, Hoodies, Varsity Jackets, and Baggy/Cargo Pants.
- **Interactive Product Modal:** Image switcher, color picker, size selector, and stock badge.
- **Size Chart Guide:** Pop-up modal with exact streetwear chest, length, and sleeve measurements.
- **Slide-out Cart Drawer:** Real-time quantity adjustment and free delivery progress indicator.
- **1-Page Cash on Delivery Checkout:** Tailored for Bangladesh with instant delivery fee calculation:
  - Inside Dhaka: ৳70
  - Outside Dhaka: ৳130
  - Free delivery over ৳2,000
- **Direct WhatsApp Order Sync:** Generates pre-filled WhatsApp order messages.
- **Live Admin Orders Panel:** Track all placed orders in real-time right inside the app!
